# IkeyWorld — каталог игр

Статический сайт для GitHub Pages. Сейчас представлена бесплатная Windows-демоверсия «Театр забытых судеб» 0.8.1. Сборка и платный хостинг не нужны.

## Локальный просмотр

Из этой папки: `python -m http.server 8765 --directory dist`. Откройте http://localhost:8765.

## Публикация на GitHub

Репозиторий: `IkeyWorld/ikeyworld-games`. Сайт: `https://ikeyworld.github.io/ikeyworld-games/` после успешного запуска Pages.

1. Войдите в GitHub через Git Credential Manager. Не вставляйте токены в файлы проекта.
2. Положите проверенный Windows ZIP в `dist/downloads/Teatr_Zabytyh_Sudeb_v0.8.1_Windows.zip`.
3. Выполните `python scripts/publish.py`. Скрипт проверяет архив, использует только аккаунт IkeyWorld, создаёт отдельный публичный репозиторий, выкладывает ZIP в Releases, заменяет ссылки и отправляет сайт. Настройка Pages использует GitHub Actions.
4. Проверьте зелёный запуск `Publish game catalog` в Actions. Если создание Pages не поддерживается правами токена: Settings → Pages → Source → GitHub Actions, затем повторите запуск workflow.

Сайт и исходники игры разделены. Рабочие документы, исходники Godot, видео с рекламой и секреты в этот репозиторий не входят. Бинарные ZIP игнорируются Git; игрок скачивает их из GitHub Releases.

## Добавить следующую игру

Добавьте объект в `dist/catalog.js` и скриншот в `dist/assets/`. Карточка появится автоматически. Укажите собственные `tags`, `download`, платформу и размер. Загрузите игровой архив отдельным GitHub Release. Обновите вводный текст сайта, если коллекция уже выросла.

## Обновить демоверсию

Создайте новый Release с архивом, обновите ссылку, версию, размер и SHA-256 в `dist/catalog.js` и блоке скачивания `dist/index.html`. Затем `git add .`, `git commit`, `git push` — Pages обновится автоматически. `publish.py` рассчитан на первую публикацию версии 0.8.1.

## Структура

- `dist/` — готовый сайт, без npm и внешних CDN.
- `dist/catalog.js` — каталог игр.
- `scripts/check_site.py` — проверка ресурсов, относительных путей и ссылок.
- `.github/workflows/pages.yml` — публикация Pages.

Шрифт Neucha распространяется по SIL OFL; лицензия в `dist/assets/NEUCHA-OFL.txt`. Иллюстрации и скриншоты взяты из нашей игры. Открытая лицензия на игровые изображения и саму игру этим репозиторием не предоставляется.
