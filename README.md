# PunkPort 🎮

**PunkPort** — независимая игровая площадка. Первая версия — настоящий адаптивный сайт на GitHub Pages с каталогом, поиском, фильтрами, карточками игр и избранным (localStorage).

**Сайт:** https://ikeyworld.github.io/ikeyworld-games/

## Что уже работает
- Главная страница, каталог, разделы «Избранное», «Обновления» и «О платформе»
- Поиск по названию, описанию и тегам
- Фильтрация по жанрам и сортировка
- Избранное сохраняется в браузере текущего устройства
- Детальные окна игр с адресными ссылками вида `#game/game-id`, копирование ссылки
- Поддержка мобильных экранов и клавиатуры
- Карточки автоматически открывают кнопку **«Скачать»**, только когда в каталоге есть корректная HTTPS-ссылка на опубликованную сборку и статус `released`
- Автоматическая сборка и деплой GitHub Pages после коммита в `main`

## Что ещё НЕ работает
GitHub Pages размещает только **статический сайт**. На текущем этапе **нет** настоящих регистраций, аккаунтов, чата, кооперативного серверного API, облачных сохранений или отдельного Windows-лаунчера. Кнопка «Гость» честно сообщает об этом. Ни один проект не помечен как опубликованная игра без реальной сборки.

Для следующих этапов нужен сервер (API + БД) и отдельный лаунчер. Не храните пользовательские пароли или приватные токены в этом репозитории.

## Исправление отображения / оформление

Основная CSS-тема хранится в `dist/style.css` и **автоматически встраивается в `dist/index.html`** перед публикацией GitHub Pages. Это убирает критическую зависимость от отдельной загрузки CSS: меню, hero, карточки и адаптивность должны сохраняться даже при проблемах с внешними стилями. Для правок стиля редактируйте `dist/style.css` и запустите `python scripts/embed_css.py`. Выпуск на Pages выполнит ту же операцию автоматически.

## Локальный запуск

```bash
python -m http.server 8765 --directory dist
```

Откройте http://localhost:8765

Для проверки:
```bash
python scripts/embed_css.py
python scripts/check_site.py
node --check dist/app.js
node --check dist/catalog.js
```

## Как добавить свою игру
Редактируйте массив `window.PUNKPORT_GAMES` в `dist/catalog.js`. Для каждой записи требуются уникальный `id`, имя, жанр, описания, теги и визуальная тема `fantasy`, `tech` или `sandbox`.

Пока сборка отсутствует:
```js
status: "development",
download: null,
version: null
```

Когда **реально загрузите** проверенную версию (например, в GitHub Releases или R2), укажите:
```js
status: "released",
download: "https://example.com/real-verified-build.zip",
version: "1.0.0"
```
Сайт покажет работающую кнопку скачивания. Перед публикацией проверяйте архив антивирусом и SHA-256, лицензию на ассеты и реальные системные требования. Не добавляйте фиктивные ссылки или непроверенные сборки.

## Публикация
Пуш в `main` запускает workflow `.github/workflows/pages.yml` с автоматической проверкой ресурсов и размещением содержимого `dist/`.

Если Pages ещё не настроен: репозиторий → Settings → Pages → Source: **GitHub Actions**.

## Структура
- `dist/index.html` — разметка страницы и доступная семантическая структура
- `dist/style.css` — адаптивное оформление
- `dist/catalog.js` — данные личных игр
- `dist/app.js` — клиентская функциональность
- `dist/assets/` — собственные векторные иконки и Open Graph-баннер
- `scripts/check_site.py` — тест разметки и путей
- `.github/workflows/pages.yml` — автоматическая публикация

## Принципы
Не публиковать недоступные игры как готовые, не симулировать аккаунты, не хранить секреты в статике. PunkPort развивается поэтапно.
